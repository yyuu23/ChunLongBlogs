# AI 对话功能验证指南，更新

> 覆盖 AI 对话模块至今的全部改动。每一项都给出：**在哪测 → 输入什么 → 应该看到什么**。
> 全程只需要浏览器 + 本地 dev server（`npm run dev`，端口 3000），不需要其它工具。

## 0. 准备

1. 项目根目录跑 `npm run dev`，等控制台出现 `Ready`。
2. `.env` 里三家 Key（DEEPSEEK / GLM / QWEN）与 TAVILY_API_KEY 均已配置——联网搜索与三模型切换依赖它们。
3. 建议先用无痕窗口测试（localStorage 干净，避免旧选择残留干扰）。
4. 后台管理入口 `http://localhost:3000/admin`，账号密码在 `.env`（ADMIN_USERNAME / ADMIN_PASSWORD）。

---

## 1. 基础对话与复制按钮（/chat 页）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开 `/chat`，输入「你好」发送 | AI 流式打字回复，光标处有 ▍ 符号 |
| 2 | 等 AI 回复完，鼠标悬停回复气泡下方 | 出现复制小按钮 |
| 3 | 点击复制，到任意输入框粘贴 | 粘贴出完整回复文本；按钮变 ✓ 两秒（http 环境也有效，失败会变 ✗） |
| 4 | 连续发几条消息 | 消息卡自动滚到底；输入框上出现 3 个轮换的快捷追问胶囊 |

## 2. 博客数据问答（AI 查真实数据库）

这类问题 AI 会**先调用站内工具查库再回答**，数据是真的，不是编的。

| 输入 | 预期 |
|---|---|
| 「帮我列出这个博客的所有文章，做一个 list」 | 回复中出现**文章卡片列表**（封面/标题/日期/分类，可点击跳转），数据与后台文章一致 |
| 「最近写了什么说说？」 | 出现**说说卡片**（内容/日期/心情/配图） |
| 「相册里都有什么？」 | 出现**相册卡片**（封面/标题/照片数） |
| 「音乐馆里有什么歌/歌单？」 | AI 先显示 🔍「查询音乐馆」，回答真实歌单与歌曲（多曲目时会渲染**音乐卡片**：歌名/歌手/时长） |
| 「这个博客现在有多少篇文章、多少说说？」 | 出现**统计卡片**（emoji 图标 + 数字） |
| 「利物浦和曼联这赛季谁更有竞争力？」 | 出现 **VS 对比卡片**（左右两栏要点 + 一句话结论），并诚实说明知识可能不是最新 |

验证要点：
- 等待期间气泡位置会显示 🔍「查询文章列表…」这类**工具执行提示**；
- 回复完成后气泡下方有「查询了什么」徽章，**点开能看到每一步调用的工具名和参数**（工具透明化）；
- 卡片里的数字与 `/admin` 后台的实际数据一致。

## 3. 联网搜索（Tavily 已配置，已实测打通）

| 输入 | 预期 |
|---|---|
| 「Next.js 目前最新的正式版本号是多少？」 | 等待期出现 🔍「联网搜索…」，回答基于真实搜索结果并**附来源链接**（如 nextjs.org/blog） |

说明：联网搜索与思考强度**无关**（任何档位都能搜）。提示词已要求：凡涉时效性内容（最新/今天/这个赛季/新版本/价格）必须先搜索再回答。若某次没触发，多半是提问本身不带时效性词。

## 4. 话题边界（已放宽）

| 输入 | 预期 |
|---|---|
| 「帮我写一个 Python 快排」 | 正常写代码（不会拒绝） |
| 「推荐几本程序员书」 | 正常回答 |
| 「今天心情不好」 | 正常陪聊，有情绪安慰 |
| 「你怎么看 XX 敏感时政事件」 | 委婉拒答（仅时政/宏观议题、医疗法律金融的重大决策类问题拒答） |

## 5. 模型选择弹窗 + 思考强度滑条（本次新功能，/chat 页）

1. 输入框上方有一个**胶囊按钮**：当前模型 logo + 模型名 + 当前档位（如「GLM 5.3 Flash · 低」）。
2. 点击胶囊 → 弹出玻璃风选择窗口：
   - 左侧 3 个模型（GLM / DeepSeek / Qwen 官方 logo + 展示名 + **真实模型 id** 小字），当前选中项有 ✓；
   - 右侧是当前模型的**拟人立绘**；
   - 底部是**思考强度滑条**，刻度随模型变化：
     - **GLM 5.3 Flash**：低 / 高 / 最高（该模型不能关思考，没有"无"档）
     - **DeepSeek V4 Flash**：无 / 低 / 高 / 最高
     - **Qwen 3.8 Flash**：无 / 低 / 中 / 最高
3. 交互验证：
   - 切换到 Qwen → 滑条变 4 档、立绘换成 Qwen 角色；
   - 把档位从「低」拉到「中」→ **立绘从悠闲版换成认真版**（低=无/低档，高=中档以上）；
   - 关掉弹窗再刷新页面 → 选择被记住（存在浏览器本地）。
4. 发一条消息 → AI 气泡头像变成**当前模型的拟人头像**（档位高时是认真版头像）。
5. 把档位拉到最高再提问 → 等待期显示 🧠「深度思考中…」，回复明显更慢更详尽。

## 6. 悬浮窗（任意页面左下角，/chat 页除外）

1. 首页点击左下角「AI 聊天」按钮 → 面板**驻底展开**：落到底部、明显加高（常规桌面视口约 640px+），打开期间看板娘自动淡出、关闭后恢复；面板顶栏的 ✕ 或再按按钮关闭。
2. **自动跟随 /chat 页选的模型和档位**（共用同一份本地存储），AI 回复带头像。
3. 发送后的等待期只有一个头像 + 气泡内三个跳动圆点（工具/思考状态也在同一气泡内切换），不再出现双头像。
4. 矮视口（如 800px 高）下面板自动收缩，顶部始终让开导航栏。

## 7. 每访客限额（15 条/小时、60 条/天，可在后台改）

快速验证法：
1. `/admin/ai-chat` → 每访客限额「每小时」改成 `3` → 保存。
2. `/chat` 连发 4 条消息 → 第 4 条被拦，出现友好提示（今日/额度用完类文案），不是报错。
3. 测完把限额改回 15 保存。

> 同 IP 每分钟限流（默认 20 次/分）与全站每日总额度（CHAT_DAILY_LIMIT，默认 500）是 .env 里的硬护栏，一般不用测。

## 8. 后台管理（/admin/ai-chat）

| 检查项 | 预期 |
|---|---|
| 供应商状态 | 三张卡片，配了 Key 的显示 ✅；`.env` 默认供应商有标注 |
| 模型预设 | 3 条默认预设，每条下方有「思考档位」徽章（与前台滑条一致）；可增删改名（上限 6） |
| 「模型名」留空 | 自动用该供应商默认模型（如 glm-5.3-flash） |
| 默认思考强度下拉 | 选项 = 默认模型的档位；选了不支持的值保存后自动钳到首档 |
| 「恢复默认预设」 | 一键重置为三条内置预设 |
| 允许访客选择开关 | 关闭后 /chat 页不再显示选择器，访客固定用默认模型 |
| 保存 | ✅ 提示；前台最多 30 秒后生效（配置缓存） |

## 9. 多语言

右上角语言切换（中/英/日/韩）→ /chat 页、弹窗、滑条刻度（Off/Low/…）、限额提示全部跟随切换。

## 10. 常见问题排查

- **AI 完全不回复**：看 `.env` 三家 Key 是否配置、dev server 是否重启过；`/admin/ai-chat` 供应商状态卡片可快速确认。
- **选了某模型没反应/回退别的模型**：该供应商 Key 未配置，预设对访客自动隐藏/回退，看 admin 页状态。
- **改了配置前台没变**：配置缓存最多 30 秒；或刷新页面。
- **联网搜索没触发**：确认 `.env` 有 `TAVILY_API_KEY`（或 `SEARCH_API_KEY`）且已重启；问题本身要带时效性词（最新/今天/这个赛季）。
- **限额测试后忘了改回**：去 `/admin/ai-chat` 恢复 15/60。
