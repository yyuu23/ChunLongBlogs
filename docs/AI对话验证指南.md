# AI 对话功能验证指南，更新

> 覆盖 AI 对话模块至今的全部改动。每一项都给出：**在哪测 → 输入什么 → 应该看到什么**。
> 全程只需要浏览器 + 本地 dev server（`npm run dev`，端口 3000），不需要其它工具。

## 0. 准备

1. 项目根目录跑 `npm run dev`，等控制台出现 `Ready`。
2. `.env` 里三家 Key（DEEPSEEK / GLM / QWEN）与 TAVILY_API_KEY 均已配置——联网搜索与三模型切换依赖它们。
3. 建议先用无痕窗口测试（localStorage 干净，避免旧选择残留干扰）。
4. 后台管理入口 `http://localhost:3000/admin`，账号密码在 `.env`（ADMIN_USERNAME / ADMIN_PASSWORD）。

## 1. 基础对话与复制按钮（/chat 页）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开 `/chat`，输入「你好」发送 | AI 流式打字回复，光标处有 ▍ 符号 |
| 2 | 等 AI 回复完，鼠标悬停回复气泡下方 | 出现复制小按钮 |
| 3 | 点击复制，到任意输入框粘贴 | 粘贴出完整回复文本；按钮变 ✓ 两秒（http 环境也有效，失败会变 ✗） |
| 4 | 连续发几条消息 | 消息卡自动滚到底；输入框上出现 3 个轮换的快捷追问胶囊 |

## 1.5 图片对话（多模态，本次新增）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | /chat 输入框点 🖼 按钮选图、**Ctrl+V 粘贴截图**，或**把图片直接拖进页面** | 输入框上方出现缩略图预览（可点 × 移除，最多 3 张） |
| 1.5 | 从桌面拖一张图到 /chat 页上方悬停（不松手） | 全页背景虚化，对话卡出现 accent 虚线框与「松手即可上传图片」提示；拖离恢复，松手即加入预览（悬浮窗面板同样支持拖入） |
| 2 | 配文字（或不配）发送 | 用户气泡显示图片缩略图；等待期状态行正常 |
| 3 | 问「这张图里有什么？」 | AI 正确描述图片内容（三家均原生多模态：GLM 5.3 Flash / Qwen 3.8 Flash / DeepSeek V4 Flash Vision） |

说明：图片纯客户端压缩后直传模型，不在服务器留存。**点击任意聊天图片可放大查看**（全屏灯箱，多图支持 ←/→ 切换、Esc/点空白关闭）；会话历史持久化 640px 预览级，重新打开会话后图片依然清晰可看。

## 1.6 思考轨迹（本次新增）

开思考档（非"无"）提问 → 回答上方出现「💭 思考过程」：流式期间实时显示思考尾部，完成后折叠、点开可回看全文（带字数）。工具徽章点开后每一步还多一行 `↳ 结果摘要`（查到了什么）。

## 2. 博客数据问答（AI 查真实数据库）

这类问题 AI 会**先调用站内工具查库再回答**，数据是真的，不是编的。

| 输入 | 预期 |
|---|---|
| 「帮我列出这个博客的所有文章，做一个 list」 | 回复中出现**文章卡片列表**（封面/标题/日期/分类，可点击跳转），数据与后台文章一致 |
| 「最近写了什么说说？」 | 出现**说说卡片**（内容/日期/心情/配图） |
| 「相册里都有什么？」 | 出现**相册卡片**（封面/标题/照片数） |
| 「音乐馆里有什么歌/歌单？」 | AI 先显示 🔍「查询音乐馆」，回答真实歌单与歌曲（多曲目时会渲染**音乐卡片**：歌名/歌手/时长） |
| 「根据我的基础推荐一个学习系列」 | AI 调用 `recommend_content` / `get_series`，最多返回 3 张可点击推荐卡，并给出系列顺序、前置知识与真实来源 |
| 「有哪些项目和互动实验？」 | AI 调用项目/实验只读工具，只列已发布项目与注册表中的实验；草稿项目和隐藏系列不会泄露 |
| 「这个博客现在有多少篇文章、多少说说？」 | 出现**统计卡片**（emoji 图标 + 数字） |
| 「利物浦和曼联这赛季谁更有竞争力？」 | 出现 **VS 对比卡片**（左右两栏要点 + 一句话结论），并诚实说明知识可能不是最新 |

验证要点：
- 等待期间气泡位置会显示 🔍「查询文章列表…」这类**工具执行提示**；
- 回复完成后气泡下方有「查询了什么」徽章，**点开能看到每一步调用的工具名和参数**（工具透明化）；
- 卡片里的数字与 `/admin` 后台的实际数据一致。

## 3. 联网搜索（Tavily 已配置，已实测打通）

| 输入 | 预期 |
|---|---|
| 「Next.js 目前最新的正式版本号是多少？」 | 等待期气泡位置出现**状态药丸**：🧠 深度思考中 → 🔍 联网搜索中·"关键词" → 正文；回答基于真实搜索结果并**附来源链接**（如 nextjs.org/blog） |

状态行说明：等待期显示阶段（接洽/思考/搜索/站内）+ 轮换趣味短语 + 耗时秒数，头像带轻微工作动画；正文一到即切换为气泡。**耗时计数能直观看到思考强度档位的效果**——"最高"档思考时间明显比"低"档长。

说明：联网搜索与思考强度**无关**（任何档位都能搜）。提示词已要求：凡涉时效性内容（最新/今天/这个赛季/新版本/价格）必须先搜索再回答。若某次没触发，多半是提问本身不带时效性词。

## 5. 模型选择弹窗 + 思考强度滑条（本次新功能，/chat 页）

1. 输入框上方有一个**胶囊按钮**：当前模型 logo + 模型名 + 当前档位（如「GLM 5.3 Flash · 低」）。
2. 点击胶囊 → 弹出玻璃风选择窗口：
   - 左侧 3 个模型（GLM / DeepSeek / Qwen 官方 logo + 展示名 + **真实模型 id** 小字），当前选中项有 ✓；
   - 右侧是当前模型的**拟人立绘**；
   - 底部是**思考强度滑条**，刻度随模型变化：
     - **GLM 5.3 Flash**：低 / 高 / 最高（该模型不能关思考，没有"无"档）
     - **DeepSeek V4 Flash**：无 / 低 / 高 / 最高
     - **Qwen 3.8 Flash**：无 / 低 / 中 / 最高
3. 交互验证：
   - 切换到 Qwen → 滑条变 4 档、立绘换成 Qwen 角色；
   - 把档位从「低」拉到「中」→ **立绘从悠闲版换成认真版**（低=无/低档，高=中档以上）；
   - 关掉弹窗再刷新页面 → 选择被记住（存在浏览器本地）。
4. 发一条消息 → AI 气泡头像变成**当前模型的拟人头像**（档位高时是认真版头像）。
5. 把档位拉到最高再提问 → 等待期显示 🧠「深度思考中…」，回复明显更慢更详尽。

## 6. 悬浮窗（任意页面左下角，/chat 页除外）

1. 首页点击左下角「AI 聊天」按钮 → 面板**驻底展开**：落到底部、明显加高（常规桌面视口约 640px+），打开期间看板娘自动淡出、关闭后恢复；面板顶栏的 ✕ 或再按按钮关闭。
2. 欢迎语下方出现 3 个站内导览问题；点击后只预填输入框，**不会自动发送、不会扣积分**。
3. 点击或戳 Live2D 看板娘仍只触发原有动作和台词，不会打开导览或发起模型请求。
4. **自动跟随 /chat 页选的模型和档位**（共用同一份本地存储），AI 回复带头像。
5. 发送后的等待期：一个带轻微动画的头像 + 状态药丸（🧠思考/🔍联网搜索·关键词/📚查站内 + 趣味短语 + 耗时），正文到达后切换为气泡，不再出现双头像。
6. 矮视口（如 800px 高）下面板自动收缩，顶部始终让开导航栏。

## 7. 积分、次数与全站成本护栏

正常配置默认启用 AI 积分，访客次数由积分余额约束：

1. `/admin/ai-chat` →「AI 积分」确认已启用，记下每日发放量、模型基准积分和思考档位倍率。
2. 用新的无痕窗口打开 `/chat`，输入区应显示当天可用积分；发送一条消息后，回答下方显示本条消耗，余额同步减少。
3. 切换模型或思考档位，模型选择器显示的单条价格应随之变化；DeepSeek 高峰时段还应出现高峰倍率提示。
4. 上游在产生内容前失败时，刚扣的积分应自动退回；余额不足时返回友好提示，不应继续请求上游模型。

关闭积分体系后，服务端才回退使用旧配置中的每访客小时/日次数限制（默认
15/60）。这两个兼容字段已经从后台表单移除，不再是日常调节入口。

无论积分是否启用，以下硬护栏始终生效：同 IP 每分钟限制
`CHAT_RATE_LIMIT`（默认 20），以及 SQLite 持久化的全站每日限制
`CHAT_DAILY_LIMIT`（默认 500）。全站日额度在 PM2 重启后不会清零；触发限制时返回
429 和 `Retry-After`。身份来自签名 `cl_visitor` Cookie，而不是客户端可伪造的
`visitorId`。完整规则和验证方法见
[公共写接口安全与运维](./PUBLIC_WRITE_SECURITY.md)。

## 10. 常见问题排查

- **AI 完全不回复**：看 `.env` 三家 Key 是否配置、dev server 是否重启过；`/admin/ai-chat` 供应商状态卡片可快速确认。
- **选了某模型没反应/回退别的模型**：该供应商 Key 未配置，预设对访客自动隐藏/回退，看 admin 页状态。
- **改了配置前台没变**：配置缓存最多 30 秒；或刷新页面。
- **联网搜索没触发**：确认 `.env` 有 `TAVILY_API_KEY`（或 `SEARCH_API_KEY`）且已重启；问题本身要带时效性词（最新/今天/这个赛季）。
- **积分余额没有按新配置变化**：每日发放在访客当天首次触达时结算；已有访客当天已结算的余额不会被后台改动追溯覆盖，可用新无痕身份验证下一次初始化。
- **所有人突然无法聊天**：检查是否触发 `CHAT_DAILY_LIMIT`；该计数存于 SQLite，重启 PM2 不会清零。不要通过删库规避，先核对调用量和配置。

## 11. 数据统计面板（/admin/stats）

| 检查项 | 预期 |
|---|---|
| 概览卡 | 今日/昨日 UV·PV、累计独立访客、AI 调用（今日/累计/带图）、音乐播放累计，数字滚动动画 |
| 流量趋势图 | 近 7/30/90 天 PV 渐变柱 + UV 红色折线，悬停显示当日数值，右上角切换时间范围 |
| AI 使用 | 供应商占比环形图（GLM/DeepSeek/Qwen 品牌色）+「模型 × 思考档位」条形图 + 工具调用排行 |
| 音乐播放 TOP | 按歌名的播放次数条形图（切歌/开播即计一次） |
| 内容资产 | 文章（发布/草稿/浏览/字数）、说说、相册照片、歌单歌曲、友链、留星 |
| 热门页面 | PV 按路径聚合的 TOP 榜 |
| 导出 | ZIP 全量包 / Markdown / CSV / JSON 四按钮；MD 是带 emoji 表格与趋势条的美观报告，可直接贴博客；ZIP 含三份文件（Windows/macOS 直接解压） |

**口径**：UV 按签名匿名访客 ID 当日去重；旧版 localStorage ID 仅在首次签发
`cl_visitor` Cookie 时迁移。PV 同会话同路径 30 秒去重；统计聚合数据按天存储
（约 1MB/年），不含 IP/UA。统计自功能上线起累积，部署新代码后
（push → Actions 自动 db:push 建表）即刻生效。

**埋点自测**：无痕窗口开几个页面 → 刷新统计页，今日 PV/UV +1；在 /chat 用不同模型/档位各发一句 → 「模型 × 思考档位」出现对应计数；播放器放一首歌 → 音乐 TOP 出现该曲。
