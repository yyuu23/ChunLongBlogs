# 漂流瓶系统设计说明

> 核心理念：**瓶子是"那一天"的容器**。瓶型/材质/瓶塞/瓶内风景全部由瓶子落库时的身份
> （kind + refKey + id）推导（`src/lib/bottle-style.ts`），零迁移，老瓶子自动获得形态。
> 唯一的新列是 `opened_at`（开瓶不可逆）。

## 1. 瓶型图鉴（8 型）

| 瓶型 | shape | 归属 |
| --- | --- | --- |
| 圆肚酒瓶 | `round` | 普通/中秋（青花瓷圆月）/夏季节气 |
| 细颈药瓶 | `slim` | 阅读成就/春·秋季节气 |
| 葫芦 | `gourd` | 音乐成就/端午（青花瓷）/夏·冬季节气 |
| 方樽 | `square` | 社交成就/重阳（青花瓷）/秋季节气 |
| 星形 | `star` | **传说成就（星空玻璃）**/**跨年纪念瓶（鎏金）** |
| 不倒翁 | `roly` | 冬季节气（自带慢摇摆 idle 动画） |
| 泪滴 | `teardrop` | 七夕（青花瓷）/探索成就/春季节气 |
| 灯笼 | `lantern` | 春节、元宵（青花瓷，带竖纹） |

## 2. 材质（5 种）

- `glass` 普通玻璃（默认）
- `frosted` 磨砂（节气瓶）
- `gilded` 鎏金（跨年瓶，金边+辉光）
- `porcelain` 青花瓷（农历节日瓶，白底蓝纹，液体半透）
- `nebula` 星空玻璃（传说成就 + 留星瓶每 17 只一支彩蛋；暗色主题下自发微光）

## 3. 瓶塞（4 种）

软木塞（默认）/ 蜡封（节气，暗红）/ 星形塞（传说与跨年，金色五角星）/ 红绸带（农历节日）。

## 4. 瓶内微缩景观

由 `data-theme` 驱动（获得时的粒子季节）：

- 樱花瓶：永续花瓣雨；萤火瓶：3 个游动光点；落叶瓶：落叶；雪瓶：4 片飘雪。
- 特殊装饰：中秋瓶悬微缩月亮；春节/元宵/跨年瓶每 ~12s 绽放一次微型烟花。
- 开过的瓶：液体剩四成、瓶塞歪斜。

## 5. 交互语义（三个手势互不干扰）

| 手势 | 行为 |
| --- | --- |
| 轻点 | 拿起端详（故事卡：名称/封存日/信笺/开瓶/投影） |
| 按住晃动 | 摇晃——液体晃动 + 冒泡 + 水声 |
| 静止长按 350ms | 拖拽重排（移动超 10px 自动取消长按，让位给摇晃） |

### 投掷物理（手写迷你物理，零依赖）

拖拽松手时若速度 > 0.35 px/ms 进入抛体：重力 0.0022 px/ms²，
撞底板 v.y×-0.45 / 水平×0.72，撞侧壁×-0.6；弹跳 3-4 次能量耗尽后
吸附最近格子、邻瓶播放撞击摆动、每次撞板播玻璃轻响（音量随撞击速度）。
局限：瓶与瓶不互相撞开堆叠；将来要完全体可升级 Matter.js（~30KB gzip）。

### 拖拽顺序持久化

`localStorage cl-bottle-order`。匿名站点的身份本身就是 localStorage 的
visitorId——换浏览器时身份（连同瓶子）一起重置，摆法放服务端无额外收益。

## 6. 音效（Web Audio 全合成，零音频文件）

拿起（双音玻璃轻响）/ 放下与撞板（低叮+闷响，音量随撞击速度）/ 摇晃（滤波噪声水声）/
开瓶（噪声"噗"+音高下坠"啵"）/ 风铃（五声音阶三连音，节日摇晃与投影用）。
每次音高 ±6% 微随机。开关在右下角设置面板「瓶子音效」（reduced-motion 强制关闭）。

## 7. 开瓶仪式（不可逆）

故事卡「开瓶」→ 瓶塞弹飞 + 金色光粒升腾（CSS）+ "啵"声 → `POST /api/bottles/open`
（属主校验 + `WHERE opened_at IS NULL` 原子更新，重复开幂等）。
开瓶后：架上液体剩四成、**节气瓶的站长信笺可读**。

## 8. 节气瓶中信

`/admin/settings` →「节气瓶中信」textarea，每行 `节气key | 语录`
（key 见 `lib/festivals.ts`，如 `solar-dongzhi`、`lunar-moon-2026`）。
存进站点配置 `festivalQuotes`，lab 页服务端透传，开瓶后展示「📖 站长的信笺」。

## 9. 瓶子投影

故事卡「投影到夜空」→ `cl-bottle-project` 事件 → 全局 `BottleProjection` 层
（复用四套粒子组件，count=42）把瓶里的季节释放在全站 30 秒，风铃开场。

## 10. 年末开瓶夜（12/25–12/31 七日窗口）

- 窗口内**任意一天**首访 → 跨年纪念瓶（`kind=newyear`，`refKey=年份`，一年一只，幂等）；
- 窗口内瓶子架夜光模式（瓶子微光、层板反光）；
- 软预告（"告诉一半"）：公告栏「🕯️ 年末开瓶夜 · 架上的瓶子亮了」+
  看板娘台词（节日当天则节日行优先）；跨年瓶的具体获得方式不公布，留作彩蛋。

## 11. 瓶子来源一览

| kind | 来源 | 唯一键 |
