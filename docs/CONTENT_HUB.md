# 内容、系列与 AI 导览

本文记录系列、项目作品集、RAG 索引和站内 AI 导览的维护边界与验收方式。

## 数据边界

- 系列是 SQLite 中的单层逻辑目录，不对应 `content/posts/` 下的物理文件夹；一篇文章最多属于一个主系列。
- 删除系列只解除 `posts.seriesId` 外键，不删除文章。草稿系列不会进入公开页面或 AI 工具。
- 项目可以关联多篇文章和一个实验室 slug。只有 `published` 项目及已发布关联文章能被公开查询。
- 后台导出格式 version 2 包含 `series`、`projects` 和 `projectPosts`；导入仍兼容 version 1。

部署后运行 `npm run db:push` 会新增系列、项目、关联表、文章字段和索引状态表，无需数据回填。升级前仍应按部署手册备份 `data/db.sqlite`。

## 人工编排与 AI 建议

后台“内容中心”负责系列和项目的增删改、发布状态、文章选择与顺序。AI 整理先返回结构化预览，服务端会再次验证文章 ID、去重和权限；管理员点击“应用方案”后才在一个事务中写入。AI 不会自动修改已发布内容。

文章编辑器的“内容健康检查”会检查问题、约束、取舍、结果、复盘等结构，核验 `/posts/<slug>` 站内链接，并建议前置知识、相似文章、可能过时的说明和下一篇选题。提示只是编辑建议，不会改写正文。

## RAG 索引

- 发布或修改文章时只重建该文章的向量；转草稿或删除时移除对应向量。
- 按 Markdown 标题和自然段切块，每块带文章标题、链接、系列、分类、标签和更新时间。
- 检索使用向量相似度与关键词排序合并；没有 embedding 配置或调用失败时继续使用关键词。
- 设置页显示已发布/已索引文章数、块数、最近运行、最近成功和失败原因，并保留全量重建按钮。

## 导览与本地偏好

悬浮聊天窗和 `/chat` 共用 `GuideStarters`、推荐数据结构与只读工具。欢迎问题只预填输入框，访客确认发送后才产生模型调用。`recommend_content` 最多返回 3 项公开文章、系列、项目或实验。

完整聊天页允许访客主动保存兴趣、基础和目标。数据只写浏览器 localStorage，30 天过期；每次请求即时读取，清除后不再携带。服务端只把它当作不可信的本轮参考，不落库、不建立访客画像。

Live2D 看板娘维持原点击、拖动、主动搭话、好感度和情绪联动，不承担导览入口。

## 验收清单

1. 创建、拖拽排序、隐藏和删除系列；确认文章不会随系列删除。
2. 让 AI 整理系列，未点击应用前查询数据库应无变化；不存在或重复的文章 ID 应被拒绝。
3. 发布、更新、转草稿和删除文章，核对设置页索引状态与对应向量。
4. 分别从悬浮窗和 `/chat` 点击三条导览问题，确认只预填；发送后推荐不超过 3 项且链接可访问。
5. 保存偏好后请求会携带偏好；点击清除后 localStorage 项消失，后续请求不再携带。
6. 草稿文章、隐藏系列和草稿项目不得出现在公开页面、sitemap 或 AI 工具结果中。
7. 首页 Hero、按钮、模块顺序以及看板娘点击行为与改造前一致。
